EIC Streaming Tracking Benchmark

Given an unordered ~2 microsecond window of ePIC central-tracker hits containing exactly one buried DIS physics event on top of continuous beam/synchrotron background, reconstruct the tracks belonging to that event and tag which reconstructed objects are signal rather than overlay, within a 0.6 ms latency budget that must eventually fit inside the readout firmware.

Working draft — not yet verified as a reproducible, runnable benchmark (see Ratings below for specifics).

Summary

The EIC's innermost silicon tracking layers face synchrotron/beam-gas background occupancy roughly three orders of magnitude above the true deep-inelastic-scattering (DIS) signal rate, and ePIC's streaming readout has no hardware trigger to filter this inline. This benchmark asks a model to jointly (a) group an unordered set of tracker hits into tracks belonging to the one true signal event in the window, and (b) tag signal vs. background hits/tracks using relative-timing coincidence (not geometry alone), while satisfying a hard deployability budget: <=0.6 ms end-to-end latency with a path to fixed-point FPGA firmware. It is a multi-dimensional (Pareto) benchmark -- physics-quality metrics (Double Majority, technical efficiency, fake rate, per-hit/ per-track AUROC) are compared at a fixed resource/latency budget, not traded off against it freely. The reference solution (HEPTv2, an LSH point-transformer adapted from the CMS L1-trigger HEPT architecture) reaches per-hit AUROC 0.992 and Double Majority 0.597 on a small (495-event) mixed sample, with a 6-bit/48%-sparse compressed variant giving 211x fewer bit-operations at matched accuracy and fitting on-chip (127 KB). This is a working draft, not the team's finalized benchmark: canonical dataset splits are not yet frozen and the reference solution's code is not yet public -- see README.md for the full, evidence-cited gap list.
